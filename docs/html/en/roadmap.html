What this installation offers (verified)

  • 1485 opcodes: 55 MIDI, 4 OSC, 51 spectral (pvs*), 17 granular, 26 physical models, 31 virtual-analog filters, 14 SoundFont (plus samples\sf_GMbank.sf2), 22 Arduino/serial.
  • Not included: VST, FluidSynth, Ableton Link, Faust, Python.
  • Csound 7 APIs used or planned: debugger (live values, breakpoints), graph display callbacks, host audio/MIDI I/O, UDP/OSC server, ugen.h.
  • VST3: the vst3 opcodes exist (beta, GPLv3, no plugin editor windows). The VST 3.8 SDK has been MIT licensed since 2025-10-29, so the app itself can be a VST3 host.

Stage 3 — 3D visualisation and control (GPU)

  • Base: Avalonia OpenGlControlBase (OpenGL ES 3 over ANGLE/Direct3D 11), Vulkan through GpuInterop later; detachable windows for a second screen; 2D fallback if the GPU fails.
  • Views: 3D waterfall spectrogram, stereo 3D scope, XYZ pad (three channels at once), 3D spatial panner (hrtfmove2/vbap, binaural), 3D wavetable, live-performance visualiser, 3D instrument graph.

Stage 4 — Music tools

Piano roll of the score (edit notes visually), envelope editor (linseg/expseg/madsr points), table editor (GEN 10/7/2), step sequencer, transport (BPM, metronome, loop), knobs and XY pads, phone control over OSC, modern template library, instrument graph, sample waveforms, background syntax check.

Stage 5 — Big projects

Own audio engine refinements, VST3 host with plugin windows (✅ done 2026-11-04: native bridge CsoundVisualVstHost.dll, insert chain of VST3 effects and instruments after Csound in the «Windows · WASAPI» engine, plug-in editor windows, scanner in a separate process, chain and states saved — see VST3 plug-ins in the app; feeding Csound from VST3 instruments through audio channels is not done), alternative vst3 opcodes, Cabbage compatibility (✅ done 2026-11-04: tolerant parser for Cabbage 2 and Cabbage 3 JSON, «Cabbage UI» card + pop-out window with knobs, sliders, buttons, comboboxes, XY pad, keyboard, labels, groups and images driving the same channels as the sliders, stand-ins for cabbageGetValue/SetValue/Set/Get/Changed, ;@knob comments in ordinary documents (item 15), 3 examples; tested on the 280 Cabbage 2 examples — see Cabbage instruments), Ableton Link (✅ done 2026-11-04: Link 3.1.5 in the app, LINK_* channels, tools locked to the session tempo and bar, Start Stop Sync — see Ableton Link), breakpoints (✅ done 2026-11-04: gutter + F9, pause with the device playing silence, Debug panel with every variable, continue / next control cycle, line map kept across live recompiles — see Breakpoints), MIDI capture to score, Scala tunings.
